# QA checklist

- [ ] A clean checkout runs using README commands.
- [ ] Valid rows are normalized correctly.
- [ ] Blank/malformed rows are rejected with a reason.
- [ ] Duplicate emails do not duplicate output.
- [ ] Missing files and invalid headers fail clearly.
- [ ] Existing output is protected.
- [ ] Tests pass and evidence is recorded.
- [ ] No secrets or real personal data are committed.
- [ ] Demo shows an actual run, not only slides.
- [ ] Known limitations and next improvement are documented.
