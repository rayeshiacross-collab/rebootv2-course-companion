# Python practice

Start with the matching provisional lesson guide. Each folder contains a `starter.py` exercise and a `solution.py`, plus expected output and sample input where needed. Copy a lesson folder to a scratch location, open a terminal there and run `python solution.py`. File exercises 09 and 12 write their named files in that working directory. `starter.py` raises NotImplementedError until completed; this is intentional.

The solution is a reference, not evidence that you completed the challenge. Type or adapt the example, run it and explain the result. Python 3.12.14 is verified. No package installation is required.
